# RetailSystems — releases

Este repositorio solo guarda los instaladores y las actualizaciones de **RetailSystems**.
El código está en un repositorio privado aparte.

- **Instalar en una PC nueva:** en [Releases](../../releases/latest) descarga `RetailSystems-win-Setup.exe` y ejecútalo.
- **Actualizaciones:** el programa las busca solo aquí cuando entra un administrador, y pregunta antes de reiniciar.

Las versiones se publican con `vpk upload github` (ver `RELEASE.md` en el repositorio del código).
